# 角色效率岛零基础安装和使用教程

这份说明可以直接发给没有编程基础的用户。不同角色版的功能基本一致，只是名字、图片、提醒文案和图标不同。

## 这是什么

角色效率岛是一个 macOS 菜单栏小工具。打开后，它会在屏幕顶部显示一个小岛，用角色状态陪你工作、休息、喝水和接收提醒。

它可以记录工作时间、休息时间、喝水次数、AI 完成次数、打字量、速度、修正率以及 APM/EPM。输入统计只记录数量和类型，不记录你具体打了什么字。

## 安装方法

1. 下载别人发给你的 `.zip` 压缩包。
2. 双击压缩包解压，得到一个 `.app` 应用。
3. 可以把 `.app` 放进“应用程序”文件夹，也可以先放在桌面或下载文件夹里试用。
4. 第一次打开时，如果系统提示“无法验证开发者”，请右键点击这个 `.app`，选择“打开”，再点一次“打开”。
5. 打开后，看屏幕顶部或菜单栏附近是否出现角色小岛或图标。
6. 如果没有看到，可以再双击一次 `.app`，或检查菜单栏图标是否被系统隐藏。

## 第一次使用需要开的权限

macOS 可能会要求你手动打开权限，这是正常的。

### 输入监控

用于统计打字量、当前速度、平均速度、修正率以及 APM/EPM。

设置位置：

```text
系统设置 -> 隐私与安全性 -> 输入监控
```

找到这个角色效率岛应用，打开开关。打开后建议退出并重新打开应用。

### 辅助功能

用于更稳定地读取工作状态、修复权限和配合部分提醒功能。

设置位置：

```text
系统设置 -> 隐私与安全性 -> 辅助功能
```

找到这个角色效率岛应用，打开开关。打开后建议退出并重新打开应用。

### 防止休眠

只有你在面板里开启“禁止休眠”时才会生效。不开这个选项时，它不会阻止电脑休眠。

## 日常怎么用

点击顶部小岛或菜单栏图标，可以打开设置面板。

常用按钮：

- “休息 5 分钟”：进入 5 分钟休息倒计时。
- “结束休息”：提前回到工作状态。
- “暂停/继续”：暂停或继续当前计时。
- “喝水打卡”：记录一次喝水。
- “清零今日”：只清掉今天的记录。
- “清空全部”：清掉所有历史记录。
- “打开记录”：查看本地保存的记录。
- “退出”：关闭应用。

常用开关：

- “AI 完成提醒”：打开后，检测到 AI 工具完成任务时会提醒。
- “顶部常驻小岛”：控制顶部小岛是否一直显示。
- “禁止休眠”：工作时防止电脑自动睡眠。
- “登录时启动”：开机登录后自动启动这个应用。

## 定时提醒怎么用

定时提醒区域有一个总开关，下面有四个提醒项。总开关勾上时，四个提醒项会一起启用；取消时，四个提醒项会一起关闭。

每个提醒项都可以用两种写法：

- 按间隔提醒：例如 `每 50 分钟`、`每 2 小时`
- 按固定时间提醒：例如 `12:00`、`19:00`

第一项通常是“喝水”，不同角色版可能会把另外三项改成“离开椅子”“午休”“下班”等。

## 输入仪表怎么看

输入仪表显示的是今天或当前运行期间的汇总数据：

- 打字量：按键数量统计。
- 当前：最近一小段时间的输入速度。
- 修正率：退格、删除等修正操作占比。
- 均速：平均输入速度。
- APM：最近 60 秒内全部非自动重复按键和鼠标点击数，包括退格和 Delete。
- EPM：使用相同的 60 秒窗口，但排除退格和 Delete；工作状态的小岛显示这一项。

APM/EPM 使用自然经过的 60 秒，不会因为只在几秒内操作就按“活跃秒数”放大。快捷键和功能键会计入操作数，但不会计入普通打字量；滚轮和鼠标移动不计入。

如果没有足够数据，部分数值会显示为 `--`，这是正常的。

## AI 完成提醒

打开“AI 完成提醒”后，应用会尝试检测本机 AI 工具的完成状态。常见支持方向包括 Codex、Claude、Cursor、Terminal 或其他通过本地标记文件桥接的工具。

如果你只是把它当普通工作陪伴工具，也可以关掉这个功能。

## 不同角色版有什么区别

不同角色版一般只是换了这些内容：

- 应用名字和菜单栏名字。
- 顶部小岛和面板里的角色图片。
- 工作、休息、待命、喝水、AI 完成、定时提醒的文案。
- 图标和打包名。

功能、权限、数据记录逻辑通常是一样的。每个角色版都需要在自己的电脑上重新授权一次输入监控和辅助功能。

## 常见问题

### 双击后什么都没出现，菜单栏也没有图标

先确认 App 版本不低于 0.1.3。0.1.3 修复了部分新版本 macOS 上打包 App 在启动阶段读取资源失败并立即退出的问题。

如果仍然没有图标：

1. 打开“活动监视器”，搜索 App 的英文可执行文件名或中文 App 名；完全搜不到通常表示启动后立即退出。
2. 打开“访达 → 前往 → 前往文件夹”，输入 `~/Library/Logs/DiagnosticReports/`，查看是否有同名 `.ips` 文件。
3. 删除旧的解压目录，重新完整解压新版 zip，再把 App 移到“应用程序”文件夹。
4. 右键 App 选择“打开”。不要直接在聊天软件预览或压缩包内部运行。

出现过“是否允许访问文件”的提示，只表示系统曾尝试启动 App，不代表 App 已经持续运行或菜单栏组件已经成功加载。

### 打不开应用

右键点击 `.app`，选择“打开”。这是 macOS 对未上架应用的安全提示。

### 双击之后没反应

这个应用是菜单栏小工具，不会出现在 Dock 里，也不会弹出普通窗口。先看屏幕顶部有没有小岛或菜单栏图标。

如果确实没有启动，通常是 macOS 拦截了未公证应用。请右键点击 `.app`，选择“打开”；或者到“系统设置 -> 隐私与安全性”页面底部，点“仍要打开”。

### 打字量一直是 0

检查“输入监控”权限是否已经打开。打开后退出应用，再重新打开。

### 权限开了还是不生效

可以在面板里点“修复权限”，然后退出并重新打开应用。如果还是不行，在系统设置里先关掉权限再打开一次。

### 看不到顶部小岛

确认“顶部常驻小岛”已经勾选。也可以退出应用后重新打开。

### 记录在哪里

记录保存在本机的应用支持目录里。普通用户不需要手动找文件，直接点面板里的“打开记录”即可。
